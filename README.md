# JSON Formatter & Validator

⚡ Fast, beautiful JSON formatter with real-time validation and syntax highlighting.

## Features

- 🎨 **Syntax Highlighting** - Color-coded JSON output
- ✅ **Real-time Validation** - Instant error detection with line/column info
- 📋 **Format/Minify** - Prettify or compress JSON
- 📋 **Copy to Clipboard** - One-click copy
- 🎯 **No Dependencies** - Pure HTML/CSS/JavaScript
- 📱 **Responsive** - Works on mobile and desktop

## Usage

1. Open `index.html` in your browser
2. Paste JSON in the input panel
3. See validation results instantly
4. Use Format/Minify buttons as needed
5. Copy formatted JSON to clipboard

## Live Demo

Open `index.html` in any modern browser.

## Installation (Local)

```bash
git clone https://github.com/gizzardkey/json-formatter.git

cd json-formatter

start index.html
```

## Tech Stack

- HTML5
- CSS3 (with CSS variables & animations)
- Vanilla JavaScript
- Google Fonts (JetBrains Mono, Syne)
